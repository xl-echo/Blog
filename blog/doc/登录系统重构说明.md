# 登录系统重构说明

## 功能概述

本次重构实现了以下功能：

1. **开放登录系统**：任何人都可以登录，首次登录自动创建账号
2. **权限分离**：
   - 未登录用户：可以浏览文章、查看评论、查看点赞数
   - 登录用户：可以发布文章、点赞、评论、删除自己的评论

## 后端修改内容

### 1. 用户登录逻辑修改
**文件**: `UserServiceImpl.java`

- 修改了 `login` 方法，实现自动注册功能
- 如果用户名不存在，自动创建新用户
- 如果用户名存在，验证密码

### 2. 文章权限控制
**文件**: `ArticleController.java`

- `getList` - 获取文章列表：无需登录
- `getDetail` - 获取文章详情：无需登录
- `getHotList` - 获取热门文章：无需登录
- `save` - 保存文章：需要登录
- `update` - 更新文章：需要登录
- `delete` - 删除文章：需要登录

### 3. 新增功能模块

#### 点赞功能
- **实体类**: `LikePo.java`
- **DAO**: `LikeDao.java` + `LikeDao.xml`
- **Service**: `LikeService.java` + `LikeServiceImpl.java`
- **Controller**: `LikeController.java`

**API接口**:
- `POST /likeController/like` - 点赞文章（需要登录）
- `POST /likeController/unlike` - 取消点赞（需要登录）
- `GET /likeController/check` - 检查是否已点赞（无需登录）
- `GET /likeController/count` - 获取点赞数（无需登录）

#### 评论功能
- **实体类**: `CommentPo.java`
- **DAO**: `CommentDao.java` + `CommentDao.xml`
- **Service**: `CommentService.java` + `CommentServiceImpl.java`
- **Controller**: `CommentController.java`

**API接口**:
- `POST /commentController/add` - 添加评论（需要登录）
- `GET /commentController/list` - 获取评论列表（无需登录）
- `POST /commentController/delete` - 删除评论（需要登录）

## 数据库修改

### 新增表结构

**文件**: `new_tables.sql`

```sql
-- 评论表
CREATE TABLE `comment` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT,
  `article_id` bigint(20) NOT NULL,
  `user_id` bigint(20) NOT NULL,
  `username` varchar(50) DEFAULT NULL,
  `content` text,
  `create_time` datetime DEFAULT NULL,
  `update_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `idx_article_id` (`article_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 点赞表
CREATE TABLE `like` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT,
  `article_id` bigint(20) NOT NULL,
  `user_id` bigint(20) NOT NULL,
  `username` varchar(50) DEFAULT NULL,
  `create_time` datetime DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_article_user` (`article_id`,`user_id`),
  KEY `idx_article_id` (`article_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

## 使用示例

### 1. 首次登录
- 用户名: `testuser`
- 密码: `123456`
- 系统会自动创建该用户

### 2. 浏览文章（无需登录）
- 访问首页，可以查看所有文章
- 点击文章可以查看详情
- 可以查看评论和点赞数

### 3. 发布文章（需要登录）
- 登录后进入发布页面
- 填写文章标题和内容
- 提交发布

### 4. 点赞文章（需要登录）
- 在文章详情页点击点赞按钮
- 可以取消点赞

### 5. 发表评论（需要登录）
- 在文章详情页的评论区域输入内容
- 点击发表评论
- 可以删除自己的评论

## 在文章详情页使用交互组件

在文章详情页面中引入 `ArticleInteraction` 组件：

```vue
<template>
  <div>
    <!-- 文章内容 -->
    <div class="article-content">
      <h1>{{ article.title }}</h1>
      <div v-html="article.content"></div>
    </div>
    
    <!-- 交互组件 -->
    <ArticleInteraction :articleId="article.id" />
  </div>
</template>

<script>
import ArticleInteraction from '@/components/ArticleInteraction'

export default {
  components: {
    ArticleInteraction
  },
  data() {
    return {
      article: {
        id: 1,
        title: '文章标题',
        content: '文章内容'
      }
    }
  }
}
</script>
```
